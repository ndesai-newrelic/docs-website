## Syntax [#syntax]

```typescript
analyticsEventEnabled(options: { enabled: boolean }) => void

networkRequestEnabled(options: { enabled: boolean }) => void

networkErrorRequestEnabled(options: { enabled: boolean }) => void

httpResponseBodyCaptureEnabled(options: { enabled: boolean }) => void
```

## Description [#description]

Use these methods to turn features on or off after the agent starts. Each method has a matching setting that you can also set when you call `start`. For more information, see [Configure mobile monitoring settings](/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/configure-settings#capacitor-configurations).

## Return values [#return-values]

These methods do not return a value (`void`).

## Example [#example]

```typescript
import { NewRelicCapacitorPlugin } from '@newrelic/newrelic-capacitor-plugin';

// Stop reporting successful HTTP requests
NewRelicCapacitorPlugin.networkRequestEnabled({ enabled: false });

// Stop capturing HTTP response bodies
NewRelicCapacitorPlugin.httpResponseBodyCaptureEnabled({ enabled: false });

// Resume reporting network errors
NewRelicCapacitorPlugin.networkErrorRequestEnabled({ enabled: true });

// Android only
NewRelicCapacitorPlugin.analyticsEventEnabled({ enabled: false });
```
