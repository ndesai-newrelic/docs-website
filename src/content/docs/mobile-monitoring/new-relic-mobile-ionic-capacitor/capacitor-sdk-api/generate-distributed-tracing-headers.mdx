## Syntax [#syntax]

```typescript
generateDistributedTracingHeaders(options?: {}) => Promise<DTHeaders>
```

## Description [#description]

Generates the headers and trace attributes that are required for manual distributed tracing and HTTP instrumentation. Add the headers to your outgoing request, then pass the same object as `traceAttributes` to [`noticeHttpTransaction`](/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/network-request-success) to connect the request to its trace.

The Capacitor agent automatically adds distributed tracing headers to `fetch` and `XMLHttpRequest` calls when `distributedTracingEnabled` is `true` (the default). You only need this method for requests that the agent does not instrument automatically. For more information on the setting, see [Configure mobile monitoring settings](/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/configure-settings#capacitor-configurations).

## Parameters [#parameters]

This method takes an optional empty options object (`{}`).

## Example [#example]

```typescript
import { CapacitorHttp } from '@capacitor/core';
import { NewRelicCapacitorPlugin } from '@newrelic/newrelic-capacitor-plugin';

const url = 'https://example.com/api/orders';
const dtHeaders = await NewRelicCapacitorPlugin.generateDistributedTracingHeaders();

const requestHeaders: Record<string, string> = {
  traceparent: dtHeaders.traceparent as string,
  tracestate: dtHeaders.tracestate as string,
};
if (dtHeaders.newrelic) {
  requestHeaders['newrelic'] = dtHeaders.newrelic;
}

const startTime = Date.now();
const response = await CapacitorHttp.get({ url, headers: requestHeaders });
const body = typeof response.data === 'string' ? response.data : JSON.stringify(response.data);

NewRelicCapacitorPlugin.noticeHttpTransaction({
  url,
  method: 'GET',
  status: response.status,
  startTime,
  endTime: Date.now(),
  bytesSent: 0,
  bytesReceived: body.length,
  body,
  traceAttributes: dtHeaders,
});
```
