<Callout variant="important">
  These methods are intended for SDKs that wrap the iOS agent, such as cross-platform framework plugins. If you are instrumenting a native iOS or tvOS app, you don't need them.
</Callout>

## Set the build platform [#set-platform]

### Syntax [#set-platform-syntax]

#### Objective-C [#set-platform-objc]

```objectivec
+ (void)setPlatform:(NRMAApplicationPlatform)platform;
```

#### Swift [#set-platform-swift]

```swift
NewRelic.setPlatform(_ platform: NRMAApplicationPlatform)
```

### Description [#set-platform-description]

Sets the platform that the app was built with. The default is `NRMAPlatform_Native`. The agent can detect some platforms automatically.

The `NRMAApplicationPlatform` values, defined in `NRConstants.h`, are:

* `NRMAPlatform_Native`
* `NRMAPlatform_Cordova`
* `NRMAPlatform_PhoneGap`
* `NRMAPlatform_Xamarin`
* `NRMAPlatform_Unity`
* `NRMAPlatform_Appcelerator`
* `NRMAPlatform_ReactNative`
* `NRMAPlatform_Flutter`
* `NRMAPlatform_Capacitor`
* `NRMAPlatform_MAUI`
* `NRMAPlatform_Unreal`

## Record a handled exception from a stack trace [#record-stack-trace]

### Syntax [#record-stack-trace-syntax]

#### Objective-C [#record-stack-trace-objc]

```objectivec
+ (void)recordHandledExceptionWithStackTrace:(NSDictionary *)exceptionDictionary;
```

#### Swift [#record-stack-trace-swift]

```swift
NewRelic.recordHandledExceptionWithStackTrace(_ exceptionDictionary: [AnyHashable: Any])
```

### Description [#record-stack-trace-description]

Records a handled exception from a dictionary that describes the exception and its stack trace. Use this method when the exception didn't originate in native code, so you don't have an `NSException`. For native exceptions, use [`recordHandledException`](/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/record-handled-exceptions) or [`recordError`](/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/record-errors).

The agent reads these keys from the dictionary:

* `name`: The name of the exception.
* `reason`: The reason, or message, of the exception.
* `stackTraceElements`: An array of dictionaries, one for each stack frame. Each frame can have the keys `class`, `method`, `file`, and `line`. The agent uses a blank value when `class`, `method`, or `file` is missing, and a line number of `1` when `line` is missing.

The agent also adds the entries in the dictionary to the handled exception event as attributes, subject to attribute validation. This method returns `void`.

### Example [#record-stack-trace-example]

#### Objective-C [#record-stack-trace-example-objc]

```objectivec
[NewRelic recordHandledExceptionWithStackTrace:@{
    @"name": @"TypeError",
    @"reason": @"undefined is not a function",
    @"stackTraceElements": @[
        @{@"class": @"HomeScreen", @"method": @"onPress", @"file": @"HomeScreen.js", @"line": @"42"}
    ],
    @"framework": @"Flutter"
}];
```

#### Swift [#record-stack-trace-example-swift]

```swift
NewRelic.recordHandledExceptionWithStackTrace([
    "name": "TypeError",
    "reason": "undefined is not a function",
    "stackTraceElements": [
        ["class": "HomeScreen", "method": "onPress", "file": "HomeScreen.js", "line": "42"]
    ],
    "framework": "Flutter"
])
```
