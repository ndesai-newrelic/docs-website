## Syntax [#syntax]

`withDeviceID` is a builder method. Call it on the object returned by `withApplicationToken()`, before you call `start()`.

### Java [#java]

```java
NewRelic.withApplicationToken(String appToken).withDeviceID(String deviceID).start(Context context);
```

### Kotlin [#kotlin]

```kotlin
NewRelic.withApplicationToken(appToken: String).withDeviceID(deviceID: String?).start(context: Context)
```

## Description [#description]

By default, the Android agent generates a random, persistent identifier for each device. This method lets you override that value with your own device identifier.

The agent trims whitespace from the value and truncates values longer than 40 characters. If you pass `null` or an empty string, the agent uses the device ID `0`.

## Example [#example]

### Java [#java-example]

```java
NewRelic.withApplicationToken("<YOUR_APP_TOKEN>")
    .withDeviceID("my-device-id")
    .start(this.getApplication());
```

### Kotlin [#kotlin-example]

```kotlin
NewRelic.withApplicationToken("<YOUR_APP_TOKEN>")
    .withDeviceID("my-device-id")
    .start(this.application)
```
