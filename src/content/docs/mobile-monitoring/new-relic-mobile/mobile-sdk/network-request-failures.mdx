      ## Syntax [#syntax]

      ### Java [#java]

```java
// Record a failure using a NetworkFailure value
NewRelic.noticeNetworkFailure(String url, String httpMethod, long startTimeMs, long endTimeMs, NetworkFailure failure);

// Record a failure using a NetworkFailure value and a message
NewRelic.noticeNetworkFailure(String url, String httpMethod, long startTimeMs, long endTimeMs, NetworkFailure failure, String message);

// Record a failure using a NetworkFailure value, a message, and distributed tracing attributes
NewRelic.noticeNetworkFailure(String url, String httpMethod, long startTimeMs, long endTimeMs, NetworkFailure failure, String message, Map<String, Object> traceAttributes);

// Record a failure using an exception
NewRelic.noticeNetworkFailure(String url, String httpMethod, long startTimeMs, long endTimeMs, Exception exception);

// Record a failure with all arguments passed as a map of attributes
NewRelic.noticeNetworkFailure(Map<String, Object> attributes);
```

      ## Description [#description]

      The New Relic Android SDK API provides several methods to [track network requests](/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/network-request-success/). If a network request fails, you can record details about the failure with `noticeNetworkFailure`. In most cases, place this call inside exception handlers, such as catch blocks.

      The time values are milliseconds since the epoch, not `System.nanoTime()` values. The agent calculates the duration of the request as `endTimeMs - startTimeMs` and reports it in seconds.

      ### Network failure values [#network-failure-values]

      The `NetworkFailure` enum (`com.newrelic.agent.android.util.NetworkFailure`) has these values:

      * `Unknown`
      * `BadURL`
      * `TimedOut`
      * `CannotConnectToHost`
      * `DNSLookupFailed`
      * `BadServerResponse`
      * `SecureConnectionFailed`

      You can convert an exception to a failure value with `NetworkFailure.exceptionToNetworkFailure(Exception e)`. Exceptions that the agent doesn't recognize are converted to `Unknown`.

      ### Pass the failure as a map [#map-attributes]

      When you call `noticeNetworkFailure(Map<String, Object> attributes)`, use these keys. The `startTimeMs`, `endTimeMs`, and `errorCode` values must be passed as strings, for example `"1001"`. If a value can't be parsed as a number, the agent logs an error and records a handled exception instead of the failure.

      * `url`: String
      * `httpMethod`: String
      * `startTimeMs`: String containing a long
      * `endTimeMs`: String containing a long
      * `errorCode`: String containing the error code of a `NetworkFailure` value, such as `"-1001"` for `TimedOut`. Unrecognized codes are recorded as `Unknown`.
      * `message`: String (optional)
      * `traceAttributes`: `Map<String, Object>` (optional)

      ## Examples [#examples]

      Here's an example of an error listener that uses an error as part of the noticed network failure to New Relic:

      ### Java [#java-example]

```java
new Response.ErrorListener() {
  @Override
  public void onErrorResponse(VolleyError error) {
    NewRelic.noticeNetworkFailure(badUrl, "GET", startTimeMs,
        System.currentTimeMillis(), NetworkFailure.exceptionToNetworkFailure(error));
  }
}
```

      ### Kotlin [#kotlin-example]

```kotlin
Response.ErrorListener { error ->
    NewRelic.noticeNetworkFailure(
        badUrl,
        "GET",
        startTimeMs,
        System.currentTimeMillis(),
        NetworkFailure.exceptionToNetworkFailure(error)
    )
}
```

      ### Record an exception from a catch block [#exception-example]

      This example passes the exception directly. The agent translates it into a network failure and uses the exception message as the failure message.

      #### Java [#java-exception]

```java
long startTimeMs = System.currentTimeMillis();
try {
    HttpURLConnection connection = (HttpURLConnection) new URL(url).openConnection();
    connection.getResponseCode();
} catch (IOException e) {
    NewRelic.noticeNetworkFailure(url, "GET", startTimeMs, System.currentTimeMillis(), e);
}
```

      #### Kotlin [#kotlin-exception]

```kotlin
val startTimeMs = System.currentTimeMillis()
try {
    val connection = URL(url).openConnection() as HttpURLConnection
    connection.responseCode
} catch (e: IOException) {
    NewRelic.noticeNetworkFailure(url, "GET", startTimeMs, System.currentTimeMillis(), e)
}
```

      ### Record a failure with a message [#message-example]

      #### Java [#java-message]

```java
NewRelic.noticeNetworkFailure(url, "POST", startTimeMs, System.currentTimeMillis(),
    NetworkFailure.TimedOut, "Checkout request timed out after 30 seconds");
```

      #### Kotlin [#kotlin-message]

```kotlin

    NetworkFailure.TimedOut, "Checkout request timed out after 30 seconds")
```
