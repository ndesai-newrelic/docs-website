## Syntax [#syntax]

### Swift [#swift]

```swift
func NRTrackView(name: String? = nil) -> some View
```

## Requirements [#requirements]

* iOS 13 or higher, or tvOS 13 or higher.
* Swift only. `NRTrackView` is a SwiftUI view modifier, so it isn't available from Objective-C.

## Description [#description]

`NRTrackView` is a modifier that you add to a SwiftUI view. When the view appears, the agent starts an interaction trace with [`startInteraction`](/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/start-interaction). When the view disappears, the agent stops that interaction with [`stopCurrentInteraction`](/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/stop-interaction).

If you don't pass a name, the agent uses the name of the view's type.

## Example [#example]

### Swift [#swift-example]

```swift
import SwiftUI
import NewRelic

struct CheckoutView: View {
    var body: some View {
        VStack {
            Text("Checkout")
        }
        .NRTrackView(name: "Checkout")
    }
}
```
