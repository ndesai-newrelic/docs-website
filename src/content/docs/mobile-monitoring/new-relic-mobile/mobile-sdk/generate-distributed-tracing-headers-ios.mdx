## Syntax [#syntax]

### Objective-C [#objc]

```objectivec
+ (NSDictionary<NSString *, NSString *> *)generateDistributedTracingHeaders;

// Agent version 7.7.8 and higher
+ (NSDictionary<NSString *, NSString *> *)generateDistributedTracingContext;
```

### Swift [#swift]

```swift
NewRelic.generateDistributedTracingHeaders() -> [String: String]

// Agent version 7.7.8 and higher
NewRelic.generateDistributedTracingContext() -> [String: String]
```

## Description [#description]

The iOS agent adds distributed tracing headers to network requests that it instruments automatically. For requests that the agent doesn't instrument, such as requests made with a custom networking stack, use these methods to create the headers yourself, add them to your request, and then report the request with [`noticeNetworkRequest`](/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/network-request-success). For more about how distributed tracing works in mobile apps, see [How New Relic distributed tracing works](/docs/understand-dependencies/distributed-tracing/get-started/how-new-relic-distributed-tracing-works/#no-sampling).

* `generateDistributedTracingHeaders` returns the W3C trace context headers, `traceparent` and `tracestate`, for a new trace. Add these headers to your outgoing request.
* `generateDistributedTracingContext` (agent version 7.7.8 and higher) creates one trace and returns everything you need to both propagate and report it. The dictionary contains the `traceparent` and `tracestate` headers, plus the identity of the trace in the `trace.id`, `id`, and `guid` entries. Pass the dictionary to the `traceHeaders` parameter of `noticeNetworkRequest` or [`noticeNetworkFailure`](/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/network-request-failures) so that the event is reported against the same trace. Prefer this method when your code both makes and reports the request, such as in a cross-platform agent.

The distributed tracing feature flag `NRFeatureFlag_DistributedTracing` is enabled by default. For details, see [Configure mobile monitoring settings](/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/configure-settings#ios-dt).

## Return values [#return-values]

Both methods return an `NSDictionary` with string keys and string values. `generateDistributedTracingHeaders` returns the headers only. `generateDistributedTracingContext` returns the headers plus the trace identity entries.

## Examples [#examples]

### Objective-C [#obj-c]

Here's an example of adding the headers to a request that you send with your own networking stack:

```objectivec
NSMutableURLRequest *request = [NSMutableURLRequest requestWithURL:[NSURL URLWithString:@"https://www.newrelic.com"]];

NSDictionary<NSString *, NSString *> *headers = [NewRelic generateDistributedTracingHeaders];
[headers enumerateKeysAndObjectsUsingBlock:^(NSString *name, NSString *value, BOOL *stop) {
    [request setValue:value forHTTPHeaderField:name];
}];
```

Here's an example that propagates and reports the same trace:

```objectivec
NSDictionary<NSString *, NSString *> *context = [NewRelic generateDistributedTracingContext];
[request setValue:context[@"traceparent"] forHTTPHeaderField:@"traceparent"];
[request setValue:context[@"tracestate"] forHTTPHeaderField:@"tracestate"];

NRTimer *timer = [NewRelic createAndStartTimer];
// ... perform the request ...

[NewRelic noticeNetworkRequestForURL:request.URL httpMethod:@"GET" withTimer:timer
                     responseHeaders:@{} statusCode:200 bytesSent:0 bytesReceived:1024
                        responseData:[NSData data] traceHeaders:context andParams:nil];
```

### Swift [#swift]

Here's an example of adding the headers to a request that you send with your own networking stack:

```swift
var request = URLRequest(url: URL(string: "https://www.newrelic.com")!)

for (name, value) in NewRelic.generateDistributedTracingHeaders() {
    request.setValue(value, forHTTPHeaderField: name)
}
```

Here's an example that propagates and reports the same trace:

```swift
let context = NewRelic.generateDistributedTracingContext()
request.setValue(context["traceparent"], forHTTPHeaderField: "traceparent")
request.setValue(context["tracestate"], forHTTPHeaderField: "tracestate")

let timer = NewRelic.createAndStartTimer()
// ... perform the request ...

NewRelic.noticeNetworkRequest(for: request.url, httpMethod: "GET", with: timer,
                              responseHeaders: [:], statusCode: 200, bytesSent: 0, bytesReceived: 1024,
                              responseData: Data(), traceHeaders: context, andParams: nil)
```
