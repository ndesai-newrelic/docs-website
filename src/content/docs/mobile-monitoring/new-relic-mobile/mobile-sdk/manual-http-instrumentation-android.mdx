The New Relic Android agent automatically records HTTP requests made with the clients it instruments, and adds distributed tracing headers to them. If your app makes requests with a client the agent doesn't instrument, such as Cronet or some Ktor engines, you can instrument those requests yourself with the agent's SDK methods. This guide shows how to record a request, send distributed tracing headers with it, and report failures, using several HTTP clients as examples.

## When you need manual instrumentation [#when]

The Gradle plugin rewrites calls to the following APIs at build time. The agent records requests made through them, and adds distributed tracing headers, without any code changes:

* `HttpURLConnection` (calls to `URL.openConnection()`)
* OkHttp 2, and OkHttp 3 and 4 (calls to `OkHttpClient.newCall()` and `OkUrlFactory`)
* Apache HTTP client `execute()` calls
* Retrofit 1.x clients (`RestAdapter.Builder.setClient()`)

For the supported client versions, see [Android agent compatibility and requirements](/docs/mobile-monitoring/new-relic-mobile-android/get-started/new-relic-android-compatibility-requirements).

The agent's instrumentation rules contain no entries for any other client library. Requests need manual instrumentation when they don't pass through one of the call sites above. For example:

* **Cronet.** The agent has no rules for Cronet (`CronetEngine` and `UrlRequest`), so Cronet requests aren't recorded automatically. See [Cronet](#cronet).
* **Ktor, depending on the engine.** The agent has no rules for Ktor itself. Ktor's OkHttp engine is based on OkHttp, and the Gradle plugin also transforms library dependencies in application modules, so OkHttp calls made inside that engine can already be recorded by the agent's OkHttp rules. For other engines, such as CIO, the agent has no rules. Check whether your Ktor requests already appear in New Relic before you add the plugin in this guide. See [Ktor](#ktor).
* **Any other client**, such as one that you or a library wrote yourself. See [Any other HTTP client](#generic).
* **Requests made from native (NDK/JNI) code** or from a library that does its own networking, because the agent rewrites only JVM bytecode call sites.
* **Code excluded from instrumentation**, for example by `excludePackageInstrumentation` or `excludeVariantInstrumentation` in the [Gradle plugin](/docs/mobile-monitoring/new-relic-mobile-android/install-configure/configure-new-relic-gradle-plugin). In that case you can also use the examples for [clients the agent already instruments](#instrumented).

<Callout variant="important">
  Don't manually instrument a request that the agent already instruments. The agent would record the request twice. For example, if you add the OkHttp interceptor in this guide to a client whose `newCall()` calls the agent already instruments, you get duplicate events.
</Callout>

## Manual instrumentation flow [#flow]

For every request, follow these steps:

1. **Record the start time** in milliseconds since the epoch with `System.currentTimeMillis()`. Don't use `System.nanoTime()`. The agent calculates the duration as `endTimeMs - startTimeMs` and reports it in seconds.
2. **Create a trace context** by calling `NewRelic.noticeDistributedTrace(null)`. It returns a `TraceContext` (in `com.newrelic.agent.android.distributedtracing`). The argument is an optional `Map<String, String>` of values that identify the request; pass `null` if you have none.
3. **Add the trace headers to the outgoing request.** Call `traceContext.getHeaders()` to get a set of `TraceHeader` objects, and add each `getHeaderName()` and `getHeaderValue()` pair to the request. The headers are `traceparent` and `tracestate`, the W3C standard headers. The agent no longer sends the legacy `newrelic` header.
4. **Execute the request.**
5. **Record the result.**
   * On a response, call `NewRelic.noticeHttpTransaction(...)` with the 11-argument overload that accepts `traceAttributes`, and pass `traceContext.asTraceAttributes()`. The attributes (`id`, `guid`, and `trace.id`) are added to the `MobileRequest` or `MobileRequestError` event, which links the event to the trace.
   * On an exception, call `NewRelic.noticeNetworkFailure(...)` with the overload that accepts `traceAttributes`, and pass `traceContext.asTraceAttributes()`.

For the full list of parameters, see [Track HTTP requests](/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/network-request-success) and [Track failing HTTP requests](/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/network-request-failures).

### Requirements and validation rules [#validation]

Call the SDK methods after you start the agent. The agent enforces these rules:

* `noticeHttpTransaction` throws an `IllegalArgumentException` if the URL is null, empty, or malformed, or if the HTTP method is null or empty.
* If `endTimeMs` is earlier than `startTimeMs`, `noticeHttpTransaction` and `noticeNetworkFailure` log an error and don't record the request. If the `HandledExceptions` feature flag is enabled, they also record a handled exception.
* `statusCode` is an `int`. `startTimeMs`, `endTimeMs`, `bytesSent`, and `bytesReceived` are `long` values.
* The agent records a request as a `MobileRequest` event when the status code is between 1 and 399. A status code of 400 or higher is recorded as a `MobileRequestError` event. A request with a status code of 0 or less, and no network failure, isn't recorded.
* Byte counts: pass `0` when a size is unknown. Don't pass a negative number, such as the `-1` that OkHttp and `HttpURLConnection` return for an unknown content length. The agent's own instrumentation ignores unknown sizes in the same way.
* `noticeNetworkFailure` has two kinds of overload. The overloads that take a `NetworkFailure` value, and optionally a message and `traceAttributes`, accept trace attributes. The overload that takes an `Exception` doesn't accept trace attributes, so convert the exception yourself with `NetworkFailure.exceptionToNetworkFailure(e)` and pass `e.getMessage()` as the message, as the examples do.
* Trace headers are built with account and application identifiers that the agent receives from New Relic, and the automatic instrumentation adds headers only when the `DistributedTracing` feature flag is enabled and that account information is available. The manual methods don't check this, so make sure the agent is started, and keep the `DistributedTracing` feature flag enabled (it is by default).

## Cronet [#cronet]

The agent doesn't instrument [Cronet](https://developer.android.com/develop/connectivity/cronet), so instrument each `UrlRequest` yourself. Add the Cronet dependency to your app as described in [Get started with Cronet](https://developer.android.com/develop/connectivity/cronet/start).

In Cronet, you pass a callback and an executor when you create the request. The pattern in this example is:

1. Before you build the `UrlRequest`, record the start time and create the trace context.
2. Add the trace headers with `UrlRequest.Builder.addHeader()`.
3. Report the result from the callback. `onSucceeded()` reports the response, and `onFailed()` reports the failure.

Keep these Cronet behaviors in mind:

* Cronet doesn't treat HTTP `4xx` and `5xx` status codes as errors. They arrive in `onSucceeded()`, so `noticeHttpTransaction` records them as `MobileRequestError` events.
* `onFailed()` receives a `CronetException`, which extends `IOException`. The agent's `NetworkFailure.exceptionToNetworkFailure()` doesn't recognize Cronet exceptions, so the example maps `NetworkException` error codes to `NetworkFailure` values itself. Any other failure is reported as `Unknown`.
* `onFailed()` can receive a `null` `UrlResponseInfo`.
* The example counts the response body bytes it reads in `onReadCompleted()`. `UrlResponseInfo.getReceivedByteCount()` is an alternative, but Cronet documents it as a minimum count of bytes received from the network, so the example doesn't use it. The example passes `0` for `bytesSent`; if you send a request body, pass its length.
* Cronet calls all callback methods on the threads of the executor that you pass to `newUrlRequestBuilder()`, so the SDK calls in this example run on that executor. If you need the SDK calls on a specific thread, post them to it from the callback.
* The example doesn't report canceled requests, because Cronet calls `onCanceled()` rather than `onFailed()`.
* Create a new callback for every request. The `newRequest()` method in this example does that for you.

### Java [#cronet-java]

```java
import com.newrelic.agent.android.NewRelic;
import com.newrelic.agent.android.distributedtracing.TraceContext;
import com.newrelic.agent.android.distributedtracing.TraceHeader;
import com.newrelic.agent.android.util.NetworkFailure;

import org.chromium.net.CronetEngine;
import org.chromium.net.CronetException;
import org.chromium.net.NetworkException;
import org.chromium.net.UrlRequest;
import org.chromium.net.UrlResponseInfo;

import java.nio.ByteBuffer;
import java.util.concurrent.Executor;

public class TracedCronetCallback extends UrlRequest.Callback {
    private final String url;
    private final String method;
    private final long startTimeMs;
    private final TraceContext traceContext;
    private long bytesReceived = 0;

    private TracedCronetCallback(String url, String method, long startTimeMs, TraceContext traceContext) {
        this.url = url;
        this.method = method;
        this.startTimeMs = startTimeMs;
        this.traceContext = traceContext;
    }

    public static UrlRequest newRequest(CronetEngine engine, String url, String method, Executor executor) {
        final long startTimeMs = System.currentTimeMillis();
        final TraceContext traceContext = NewRelic.noticeDistributedTrace(null);
        final TracedCronetCallback callback = new TracedCronetCallback(url, method, startTimeMs, traceContext);

        final UrlRequest.Builder builder = engine.newUrlRequestBuilder(url, callback, executor)
                .setHttpMethod(method);

        // add the traceparent and tracestate headers
        for (TraceHeader header : traceContext.getHeaders()) {
            builder.addHeader(header.getHeaderName(), header.getHeaderValue());
        }

        return builder.build();
    }

    @Override
    public void onRedirectReceived(UrlRequest request, UrlResponseInfo info, String newLocationUrl) {
        request.followRedirect();
    }

    @Override
    public void onResponseStarted(UrlRequest request, UrlResponseInfo info) {
        request.read(ByteBuffer.allocateDirect(102400));
    }

    @Override
    public void onReadCompleted(UrlRequest request, UrlResponseInfo info, ByteBuffer byteBuffer) {
        // the buffer's position is the end of the data that was just read
        bytesReceived += byteBuffer.position();
        byteBuffer.clear();
        request.read(byteBuffer);
    }

    @Override
    public void onSucceeded(UrlRequest request, UrlResponseInfo info) {
        NewRelic.noticeHttpTransaction(url, method, info.getHttpStatusCode(),
                startTimeMs, System.currentTimeMillis(),
                0,               // bytesSent: this example sends no request body
                bytesReceived,
                null, null, null,
                traceContext.asTraceAttributes());
    }

    @Override
    public void onFailed(UrlRequest request, UrlResponseInfo info, CronetException error) {
        NewRelic.noticeNetworkFailure(url, method,
                startTimeMs, System.currentTimeMillis(),
                toNetworkFailure(error), error.getMessage(),
                traceContext.asTraceAttributes());
    }

    private static NetworkFailure toNetworkFailure(CronetException error) {
        if (error instanceof NetworkException) {
            switch (((NetworkException) error).getErrorCode()) {
                case NetworkException.ERROR_HOSTNAME_NOT_RESOLVED:
                    return NetworkFailure.DNSLookupFailed;
                case NetworkException.ERROR_TIMED_OUT:
                case NetworkException.ERROR_CONNECTION_TIMED_OUT:
                    return NetworkFailure.TimedOut;
                case NetworkException.ERROR_CONNECTION_REFUSED:
                case NetworkException.ERROR_ADDRESS_UNREACHABLE:
                    return NetworkFailure.CannotConnectToHost;
                default:
                    break;
            }
        }
        return NetworkFailure.exceptionToNetworkFailure(error);
    }
}
```

Send a request with the callback:

```java
CronetEngine cronetEngine = new CronetEngine.Builder(context).build();
Executor executor = Executors.newSingleThreadExecutor();

UrlRequest request = TracedCronetCallback.newRequest(
        cronetEngine, "https://api.example.com/items", "GET", executor);
request.start();
```

### Kotlin [#cronet-kotlin]

```kotlin
import com.newrelic.agent.android.NewRelic
import com.newrelic.agent.android.distributedtracing.TraceContext
import com.newrelic.agent.android.util.NetworkFailure
import org.chromium.net.CronetEngine
import org.chromium.net.CronetException
import org.chromium.net.NetworkException
import org.chromium.net.UrlRequest
import org.chromium.net.UrlResponseInfo
import java.nio.ByteBuffer
import java.util.concurrent.Executor

class TracedCronetCallback private constructor(
    private val url: String,
    private val method: String,
    private val startTimeMs: Long,
    private val traceContext: TraceContext
) : UrlRequest.Callback() {
    private var bytesReceived = 0L

    companion object {
        fun newRequest(engine: CronetEngine, url: String, method: String, executor: Executor): UrlRequest {
            val startTimeMs = System.currentTimeMillis()
            val traceContext = NewRelic.noticeDistributedTrace(null)
            val callback = TracedCronetCallback(url, method, startTimeMs, traceContext)

            val builder = engine.newUrlRequestBuilder(url, callback, executor)
                .setHttpMethod(method)

            // add the traceparent and tracestate headers
            for (header in traceContext.headers) {
                builder.addHeader(header.headerName, header.headerValue)
            }

            return builder.build()
        }
    }

    override fun onRedirectReceived(request: UrlRequest, info: UrlResponseInfo, newLocationUrl: String) {
        request.followRedirect()
    }

    override fun onResponseStarted(request: UrlRequest, info: UrlResponseInfo) {
        request.read(ByteBuffer.allocateDirect(102400))
    }

    override fun onReadCompleted(request: UrlRequest, info: UrlResponseInfo, byteBuffer: ByteBuffer) {
        // the buffer's position is the end of the data that was just read
        bytesReceived += byteBuffer.position()
        byteBuffer.clear()
        request.read(byteBuffer)
    }

    override fun onSucceeded(request: UrlRequest, info: UrlResponseInfo) {
        NewRelic.noticeHttpTransaction(
            url, method, info.httpStatusCode,
            startTimeMs, System.currentTimeMillis(),
            0L,              // bytesSent: this example sends no request body
            bytesReceived,
            null, null, null,
            traceContext.asTraceAttributes()
        )
    }

    override fun onFailed(request: UrlRequest, info: UrlResponseInfo?, error: CronetException) {
        NewRelic.noticeNetworkFailure(
            url, method,
            startTimeMs, System.currentTimeMillis(),
            toNetworkFailure(error), error.message,
            traceContext.asTraceAttributes()
        )
    }

    private fun toNetworkFailure(error: CronetException): NetworkFailure {
        if (error is NetworkException) {
            when (error.errorCode) {
                NetworkException.ERROR_HOSTNAME_NOT_RESOLVED -> return NetworkFailure.DNSLookupFailed
                NetworkException.ERROR_TIMED_OUT,
                NetworkException.ERROR_CONNECTION_TIMED_OUT -> return NetworkFailure.TimedOut
                NetworkException.ERROR_CONNECTION_REFUSED,
                NetworkException.ERROR_ADDRESS_UNREACHABLE -> return NetworkFailure.CannotConnectToHost
            }
        }
        return NetworkFailure.exceptionToNetworkFailure(error)
    }
}
```

## Ktor [#ktor]

Ktor is a Kotlin library, so this example is in Kotlin only. Add `io.ktor:ktor-client-core` and an engine to your app, as described in [Create a new application](https://ktor.io/docs/client-create-new-application.html) and [Client engines](https://ktor.io/docs/client-engines.html) in the Ktor documentation.

Whether you need this plugin depends on the engine:

* **OkHttp engine.** The Ktor documentation describes this engine as based on OkHttp. The Gradle plugin transforms library dependencies in application modules, so the agent's OkHttp rules can apply to OkHttp calls inside the engine. Check whether these requests already appear in New Relic before you add the plugin, to avoid recording them twice.
* **Other engines, such as CIO.** The agent has no instrumentation rules for these engines. If their requests don't appear in New Relic, add the plugin.

The plugin uses the Ktor [custom client plugin API](https://ktor.io/docs/client-custom-plugins.html), which requires Ktor 2.2.0 or higher. It uses the `Send` hook, which wraps the call to `proceed(request)`, so the plugin can add headers before the request is sent and report the result or the exception afterward.

Keep these Ktor behaviors in mind:

* The plugin reports the `Content-Length` header of the response as `bytesReceived`. If the response has no `Content-Length` header, such as a chunked response, it reports `0`.
* The plugin reports the request body length as `bytesSent` when Ktor knows it, and `0` when it doesn't.
* Exceptions that Ktor throws while sending the request, such as timeouts and connection failures, are reported with `noticeNetworkFailure` and then rethrown. The plugin doesn't report coroutine cancellation.
* Ktor documents the `Send` hook as useful for handling redirects, retrying requests, and authentication, so other plugins you install can affect which calls this plugin sees. Test it with the plugins your client uses.

```kotlin
import com.newrelic.agent.android.NewRelic
import com.newrelic.agent.android.util.NetworkFailure
import io.ktor.client.plugins.api.Send
import io.ktor.client.plugins.api.createClientPlugin
import io.ktor.http.content.OutgoingContent
import io.ktor.http.contentLength
import kotlin.coroutines.cancellation.CancellationException

val NewRelicTracing = createClientPlugin("NewRelicTracing") {
    on(Send) { request ->
        val url = request.url.buildString()
        val method = request.method.value
        val startTimeMs = System.currentTimeMillis()
        val traceContext = NewRelic.noticeDistributedTrace(null)

        // add the traceparent and tracestate headers
        for (header in traceContext.headers) {
            request.headers.append(header.headerName, header.headerValue)
        }

        val bytesSent = (request.body as? OutgoingContent)?.contentLength ?: 0L

        val call = try {
            proceed(request)
        } catch (e: CancellationException) {
            throw e
        } catch (e: Exception) {
            NewRelic.noticeNetworkFailure(
                url, method,
                startTimeMs, System.currentTimeMillis(),
                NetworkFailure.exceptionToNetworkFailure(e), e.message,
                traceContext.asTraceAttributes()
            )
            throw e
        }

        val response = call.response
        NewRelic.noticeHttpTransaction(
            url, method, response.status.value,
            startTimeMs, System.currentTimeMillis(),
            bytesSent, response.contentLength() ?: 0L,
            null, null, null,
            traceContext.asTraceAttributes()
        )

        call
    }
}
```

Install the plugin when you create the client:

```kotlin
import io.ktor.client.HttpClient
import io.ktor.client.engine.cio.CIO

val client = HttpClient(CIO) {
    install(NewRelicTracing)
}
```

## Any other HTTP client [#generic]

For a client that isn't covered by the Cronet or Ktor examples, wrap the call in a small helper that follows the same flow. Your client code supplies two things: a way to add a header to the request, and a function that runs the request and returns the status code and the byte counts.

### Java [#generic-java]

```java
import com.newrelic.agent.android.NewRelic;
import com.newrelic.agent.android.distributedtracing.TraceContext;
import com.newrelic.agent.android.distributedtracing.TraceHeader;
import com.newrelic.agent.android.util.NetworkFailure;

public class TracedHttp {
    public interface HeaderSetter {
        void set(String name, String value);
    }

    public interface HttpCall<T> {
        Outcome<T> execute() throws Exception;
    }

    public static class Outcome<T> {
        final T result;
        final int statusCode;
        final long bytesSent;
        final long bytesReceived;

        public Outcome(T result, int statusCode, long bytesSent, long bytesReceived) {
            this.result = result;
            this.statusCode = statusCode;
            this.bytesSent = bytesSent;
            this.bytesReceived = bytesReceived;
        }
    }

    public static <T> T instrument(String url, String method, HeaderSetter headers, HttpCall<T> call)
            throws Exception {
        final long startTimeMs = System.currentTimeMillis();
        final TraceContext traceContext = NewRelic.noticeDistributedTrace(null);

        for (TraceHeader header : traceContext.getHeaders()) {
            headers.set(header.getHeaderName(), header.getHeaderValue());
        }

        final Outcome<T> outcome;
        try {
            outcome = call.execute();
        } catch (Exception e) {
            NewRelic.noticeNetworkFailure(url, method,
                    startTimeMs, System.currentTimeMillis(),
                    NetworkFailure.exceptionToNetworkFailure(e), e.getMessage(),
                    traceContext.asTraceAttributes());
            throw e;
        }

        NewRelic.noticeHttpTransaction(url, method, outcome.statusCode,
                startTimeMs, System.currentTimeMillis(),
                Math.max(outcome.bytesSent, 0), Math.max(outcome.bytesReceived, 0),
                null, null, null,
                traceContext.asTraceAttributes());

        return outcome.result;
    }
}
```

### Kotlin [#generic-kotlin]

```kotlin
import com.newrelic.agent.android.NewRelic
import com.newrelic.agent.android.util.NetworkFailure

class Outcome<T>(
    val result: T,
    val statusCode: Int,
    val bytesSent: Long = 0L,
    val bytesReceived: Long = 0L
)

fun <T> instrument(
    url: String,
    method: String,
    addHeader: (name: String, value: String) -> Unit,
    execute: () -> Outcome<T>
): T {
    val startTimeMs = System.currentTimeMillis()
    val traceContext = NewRelic.noticeDistributedTrace(null)

    for (header in traceContext.headers) {
        addHeader(header.headerName, header.headerValue)
    }

    val outcome = try {
        execute()
    } catch (e: Exception) {
        NewRelic.noticeNetworkFailure(
            url, method,
            startTimeMs, System.currentTimeMillis(),
            NetworkFailure.exceptionToNetworkFailure(e), e.message,
            traceContext.asTraceAttributes()
        )
        throw e
    }

    NewRelic.noticeHttpTransaction(
        url, method, outcome.statusCode,
        startTimeMs, System.currentTimeMillis(),
        maxOf(outcome.bytesSent, 0L), maxOf(outcome.bytesReceived, 0L),
        null, null, null,
        traceContext.asTraceAttributes()
    )

    return outcome.result
}
```

For example, with a hypothetical `MyClient`, call the helper like this:

```kotlin
val body = instrument(
    url = "https://api.example.com/items",
    method = "GET",
    addHeader = { name, value -> request.addHeader(name, value) }
) {
    val response = myClient.execute(request)
    Outcome(response.body, response.statusCode, bytesReceived = response.contentLength)
}
```

## Clients that the agent already instruments [#instrumented]

The agent already records requests made with `HttpURLConnection`, OkHttp, and Retrofit, and adds distributed tracing headers to them. Use the examples in this section only if you excluded your code from instrumentation, or if you need custom behavior that automatic instrumentation doesn't provide. Otherwise you record each request twice.

### HttpURLConnection [#httpurlconnection]

This example sends a `GET` request, adds the trace headers, counts the bytes it reads, and reports either the response or the failure. Use this pattern when the request isn't made through an `HttpURLConnection` call site that the agent instruments.

#### Java [#httpurlconnection-java]

```java
import com.newrelic.agent.android.NewRelic;
import com.newrelic.agent.android.distributedtracing.TraceContext;
import com.newrelic.agent.android.distributedtracing.TraceHeader;
import com.newrelic.agent.android.util.NetworkFailure;

import java.io.IOException;
import java.io.InputStream;
import java.net.HttpURLConnection;
import java.net.URL;

public int get(String urlString) throws IOException {
    final String method = "GET";
    final long startTimeMs = System.currentTimeMillis();
    final TraceContext traceContext = NewRelic.noticeDistributedTrace(null);

    HttpURLConnection connection = null;
    try {
        connection = (HttpURLConnection) new URL(urlString).openConnection();
        connection.setRequestMethod(method);

        // add the traceparent and tracestate headers
        for (TraceHeader header : traceContext.getHeaders()) {
            connection.setRequestProperty(header.getHeaderName(), header.getHeaderValue());
        }

        final int statusCode = connection.getResponseCode();

        // read the body and count the bytes received
        long bytesReceived = 0;
        final InputStream stream = statusCode >= 400
                ? connection.getErrorStream()
                : connection.getInputStream();
        if (stream != null) {
            try (InputStream in = stream) {
                final byte[] buffer = new byte[8192];
                int read;
                while ((read = in.read(buffer)) != -1) {
                    bytesReceived += read;
                }
            }
        }

        NewRelic.noticeHttpTransaction(urlString, method, statusCode,
                startTimeMs, System.currentTimeMillis(),
                0,               // bytesSent: a GET request has no body
                bytesReceived,
                null, null, null,
                traceContext.asTraceAttributes());

        return statusCode;
    } catch (IOException e) {
        NewRelic.noticeNetworkFailure(urlString, method,
                startTimeMs, System.currentTimeMillis(),
                NetworkFailure.exceptionToNetworkFailure(e), e.getMessage(),
                traceContext.asTraceAttributes());
        throw e;
    } finally {
        if (connection != null) {
            connection.disconnect();
        }
    }
}
```

#### Kotlin [#httpurlconnection-kotlin]

```kotlin
import com.newrelic.agent.android.NewRelic
import com.newrelic.agent.android.util.NetworkFailure
import java.io.IOException
import java.net.HttpURLConnection
import java.net.URL

@Throws(IOException::class)
fun get(urlString: String): Int {
    val method = "GET"
    val startTimeMs = System.currentTimeMillis()
    val traceContext = NewRelic.noticeDistributedTrace(null)

    var connection: HttpURLConnection? = null
    try {
        connection = URL(urlString).openConnection() as HttpURLConnection
        connection.requestMethod = method

        // add the traceparent and tracestate headers
        for (header in traceContext.headers) {
            connection.setRequestProperty(header.headerName, header.headerValue)
        }

        val statusCode = connection.responseCode

        // read the body and count the bytes received
        val stream = if (statusCode >= 400) connection.errorStream else connection.inputStream
        val bytesReceived = stream?.use { it.readBytes().size.toLong() } ?: 0L

        NewRelic.noticeHttpTransaction(
            urlString, method, statusCode,
            startTimeMs, System.currentTimeMillis(),
            0L,              // bytesSent: a GET request has no body
            bytesReceived,
            null, null, null,
            traceContext.asTraceAttributes()
        )

        return statusCode
    } catch (e: IOException) {
        NewRelic.noticeNetworkFailure(
            urlString, method,
            startTimeMs, System.currentTimeMillis(),
            NetworkFailure.exceptionToNetworkFailure(e), e.message,
            traceContext.asTraceAttributes()
        )
        throw e
    } finally {
        connection?.disconnect()
    }
}
```

### OkHttp interceptor [#okhttp]

An OkHttp interceptor is a good place to instrument every request a client makes. Use it for OkHttp clients whose calls the agent doesn't instrument. Because the interceptor sees the final request, it can read the request and response sizes directly.

#### Java [#okhttp-java]

```java
import com.newrelic.agent.android.NewRelic;
import com.newrelic.agent.android.distributedtracing.TraceContext;
import com.newrelic.agent.android.distributedtracing.TraceHeader;
import com.newrelic.agent.android.util.NetworkFailure;

import java.io.IOException;

import okhttp3.Interceptor;
import okhttp3.Request;
import okhttp3.Response;

public class NewRelicTracingInterceptor implements Interceptor {
    @Override
    public Response intercept(Chain chain) throws IOException {
        final long startTimeMs = System.currentTimeMillis();
        final TraceContext traceContext = NewRelic.noticeDistributedTrace(null);

        // add the traceparent and tracestate headers
        final Request.Builder builder = chain.request().newBuilder();
        for (TraceHeader header : traceContext.getHeaders()) {
            builder.header(header.getHeaderName(), header.getHeaderValue());
        }
        final Request request = builder.build();

        final String url = request.url().toString();
        final String method = request.method();
        final long bytesSent = request.body() == null ? 0 : Math.max(request.body().contentLength(), 0);

        final Response response;
        try {
            response = chain.proceed(request);
        } catch (IOException e) {
            NewRelic.noticeNetworkFailure(url, method,
                    startTimeMs, System.currentTimeMillis(),
                    NetworkFailure.exceptionToNetworkFailure(e), e.getMessage(),
                    traceContext.asTraceAttributes());
            throw e;
        }

        // contentLength() is -1 when the length is unknown
        final long bytesReceived = response.body() == null ? 0 : Math.max(response.body().contentLength(), 0);

        NewRelic.noticeHttpTransaction(url, method, response.code(),
                startTimeMs, System.currentTimeMillis(),
                bytesSent, bytesReceived,
                null, null, null,
                traceContext.asTraceAttributes());

        return response;
    }
}
```

Add the interceptor when you build the client:

```java
OkHttpClient client = new OkHttpClient.Builder()
        .addInterceptor(new NewRelicTracingInterceptor())
        .build();
```

#### Kotlin [#okhttp-kotlin]

```kotlin
import com.newrelic.agent.android.NewRelic
import com.newrelic.agent.android.util.NetworkFailure
import okhttp3.Interceptor
import okhttp3.Response
import java.io.IOException

class NewRelicTracingInterceptor : Interceptor {
    override fun intercept(chain: Interceptor.Chain): Response {
        val startTimeMs = System.currentTimeMillis()
        val traceContext = NewRelic.noticeDistributedTrace(null)

        // add the traceparent and tracestate headers
        val builder = chain.request().newBuilder()
        for (header in traceContext.headers) {
            builder.header(header.headerName, header.headerValue)
        }
        val request = builder.build()

        val url = request.url.toString()
        val method = request.method
        val bytesSent = maxOf(request.body?.contentLength() ?: 0L, 0L)

        val response = try {
            chain.proceed(request)
        } catch (e: IOException) {
            NewRelic.noticeNetworkFailure(
                url, method,
                startTimeMs, System.currentTimeMillis(),
                NetworkFailure.exceptionToNetworkFailure(e), e.message,
                traceContext.asTraceAttributes()
            )
            throw e
        }

        // contentLength() is -1 when the length is unknown
        val bytesReceived = maxOf(response.body?.contentLength() ?: 0L, 0L)

        NewRelic.noticeHttpTransaction(
            url, method, response.code,
            startTimeMs, System.currentTimeMillis(),
            bytesSent, bytesReceived,
            null, null, null,
            traceContext.asTraceAttributes()
        )

        return response
    }
}
```

Add the interceptor when you build the client:

```kotlin
val client = OkHttpClient.Builder()
    .addInterceptor(NewRelicTracingInterceptor())
    .build()
```

The Kotlin example uses the OkHttp 4 property syntax (`request.url`, `response.code`). With OkHttp 3, use the Java-style method calls (`request.url()`, `response.code()`, `response.body()`).

### Retrofit [#retrofit]

Retrofit 2 makes its requests through OkHttp, so you instrument it by adding the same interceptor to the `OkHttpClient` that you pass to Retrofit. Do this only if the agent doesn't already instrument that client.

```java
Retrofit retrofit = new Retrofit.Builder()
        .baseUrl("https://api.example.com/")
        .client(new OkHttpClient.Builder()
                .addInterceptor(new NewRelicTracingInterceptor())
                .build())
        .build();
```

```kotlin
val retrofit = Retrofit.Builder()
    .baseUrl("https://api.example.com/")
    .client(
        OkHttpClient.Builder()
            .addInterceptor(NewRelicTracingInterceptor())

    )
```

## Verify your instrumentation [#verify]

After you run your app and make a few requests:

* Query the `MobileRequest` and `MobileRequestError` event types to find the requests you recorded. Events from `noticeHttpTransaction` and `noticeNetworkFailure` carry the trace attributes you passed.
* Mobile spans appear in any New Relic distributed tracing UI where those spans are part of a trace. For tips on finding and querying them, see [New Relic Android mobile monitoring with distributed tracing](/docs/mobile-monitoring/new-relic-mobile-android/get-started/new-relic-android-and-dt) and [Understand and use the distributed tracing UI](/docs/distributed-tracing/ui-data/understand-use-distributed-tracing-ui).
* If you don't see data, make sure the `NetworkRequests` and `NetworkErrorRequests` feature flags are enabled (they are by default). For distributed tracing, you also need `AnalyticsEvents` enabled. See [Configure mobile monitoring settings](/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/configure-settings).
