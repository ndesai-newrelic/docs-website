      ## Syntax [#syntax]

      ### Java [#java]

```java
NewRelic.withApplicationVersion(string $appVersion)
```

      ### Kotlin [#kotlin]

```kotlin
NewRelic.withApplicationVersion(appVersion: String?)
```

      ## Description [#description]

      By default, the New Relic Android agent gets the app version from the `AndroidManifest.xml` or `build.gradle`. This method lets you override that value and set an app version by passing the app version. The app version is displayed as a dropdown in the New Relic UI, and you can use it to sort interactions.

      ### Objective-c [#objc]

      ## Description [#description]

      By default, New Relic uses the `CFBundleShortVersionString` when reporting the build number. But you can override the reported build number by calling this method (before calling `startWithApplicationToken`).

      ## Syntax [#react-syntax]

```typescript
setJSAppVersion(version: string): void;
```

      ## Description [#react-description]

      The React Native agent doesn't have a method to override the native app version that the Android and iOS agents report. Instead, use `setJSAppVersion()` to set the version of your JavaScript bundle. The agent adds this value to your session as the `JSBundleId` attribute and attaches it to every JavaScript error that it reports as a [`MobileJSError` event](/attribute-dictionary/?event=MobileJSError).

      The value you pass is the bundle ID that New Relic uses to match JavaScript errors to the [source map](/docs/mobile-monitoring/new-relic-monitoring-react-native/react-native-agent-js-error-reporting#retrieve-bundle-id) that symbolicates their stack traces. The `jsBundleId` of the source map you upload must be the same string.

      Call `setJSAppVersion()` right after `NewRelic.startAgent()`, at the start of your app. If you haven't called it when a JavaScript error is recorded, the agent logs an error and sends the error without a `JSBundleId`. If the value isn't a string, the agent logs an error and ignores it.

      ## Examples [#react-examples]

