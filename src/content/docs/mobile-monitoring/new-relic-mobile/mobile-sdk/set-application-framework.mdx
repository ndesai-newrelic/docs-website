## Syntax [#syntax]

`withApplicationFramework` is a builder method. Call it on the object returned by `withApplicationToken()`, before you call `start()`.

### Java [#java]

```java
NewRelic.withApplicationToken(String appToken)
    .withApplicationFramework(ApplicationFramework applicationFramework, String frameworkVersion)
    .start(Context context);
```

### Kotlin [#kotlin]

```kotlin
NewRelic.withApplicationToken(appToken: String)
    .withApplicationFramework(applicationFramework: ApplicationFramework?, frameworkVersion: String?)
    .start(context: Context)
```

## Description [#description]

Reports the framework that your app is built with, and the version of that framework. This method is mainly used by the New Relic hybrid agents (such as React Native, Flutter, and .NET MAUI), which call it for you. You only need to call it directly if you build your own framework wrapper on top of the Android agent.

The agent reports these values as the `platform` and `platformVersion` attributes. The default framework is `Native`, and the default framework version is the agent version. If you pass a `null` framework, the agent keeps the current framework and still updates the framework version.

## Example [#example]

### Java [#java-example]

```java
NewRelic.withApplicationToken("<YOUR_APP_TOKEN>")
    .withApplicationFramework(ApplicationFramework.Flutter, "3.24.0")
    .start(this.getApplication());
```

### Kotlin [#kotlin-example]

```kotlin
NewRelic.withApplicationToken("<YOUR_APP_TOKEN>")
    .withApplicationFramework(ApplicationFramework.Flutter, "3.24.0")
    .start(this.application)
```
