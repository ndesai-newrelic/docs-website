## Syntax [#syntax]

### Java [#java]

```java
NewRelic.isStarted();
```

### Kotlin [#kotlin]

```kotlin
NewRelic.isStarted(): Boolean
```

## Description [#description]

Checks whether the New Relic Android agent is currently running. Use it to avoid calling the agent from code paths that might run before the agent starts, or to confirm that your `start()` call succeeded.

## Return values [#return-values]

Returns `true` if the agent is running, or `false` if it hasn't started. If you call [`NewRelic.shutdown()`](/docs/mobile-monitoring/new-relic-mobile/mobile-sdk/shut-down-agent), the agent stops until the app restarts.

## Example [#example]

### Java [#java-example]

```java
NewRelic.withApplicationToken("<YOUR_APP_TOKEN>").start(this.getApplication());

if (NewRelic.isStarted()) {
    NewRelic.recordBreadcrumb("agent started");
}
```

### Kotlin [#kotlin-example]

```kotlin
NewRelic.withApplicationToken("<YOUR_APP_TOKEN>").start(this.application)

if (NewRelic.isStarted()) {
    NewRelic.recordBreadcrumb("agent started")
}
```
